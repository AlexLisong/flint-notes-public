# Code of Conduct

We want Flint to be a respectful place to learn and collaborate, regardless of experience, identity or background. This applies to issues, pull requests, reviews and other project spaces.

## Expected behavior

Be considerate and specific. Discuss ideas and code with evidence, welcome questions, credit others' work, and accept constructive feedback. Respect people's time and privacy.

Harassment, discrimination, threats, sexualized attention, personal attacks, doxxing and publishing private communications without consent are not acceptable.

## Reporting and enforcement

For a private report, use a private contact method listed on the repository owner's GitHub profile. If none is available, open an issue titled **Private conduct contact requested** with no names or incident details; request a confidential route before sharing the report. For threats or platform abuse, GitHub's **Report abuse** flow is also available privately. Do not use a vulnerability report for a conduct incident unless it concerns security.

Maintainers review reports with discretion and share details only as needed to investigate and respond. They may edit or remove harmful content, request a behavior change, limit participation or ban repeat or severe offenders. Responses should reflect the impact and context. A person involved in a report should not decide its outcome; concerns about an owner's conduct can be reported directly to GitHub.
